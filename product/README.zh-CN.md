# 衡研 · A股研究工作台 v0.1

这是可运行的**开发测试版**，不是已经获准销售或接通券商的交易软件。
不接收投资本金，不提供实盘下单。当前没有实时行情、商业公告源或真实支付。

## 快速使用

Windows 需安装 Python 3.11+（建议3.12），联网后双击 `product/start-windows.bat`。
启动器建立独立环境、安装产品所需依赖，随后打开 http://127.0.0.1:8765 。
如失败窗口会保留错误。启动器尚未在真实Windows上验收，不能称作已生成exe安装包。

其他系统在仓库根目录运行：

```bash
python -m venv .product-venv
# 激活此虚拟环境后
python -m pip install -r product/requirements.lock.txt
python product/launch.py
```

1. 创建账户：邮箱格式有效、密码至少12字符；尚未提供邮箱验证和密码找回。
2. 在数据中心载入合成演示数据，或导入你有权使用的CSV。
3. 在自选行情点击“研究”，任务完成后阅读、导出数据核对报告。
4. 在模拟交易提交限价单，点击“推进下一数据日”撮合；成交前可撤单。
5. 观察现金、冻结、可卖数量、成交记录和资金流水。
6. 如需测试套餐，复制 product/.env.example 为 product/.env，设置
   PRODUCT_TEST_BILLING=true 后重启。页面明确显示不扣款。生产必须关闭。

演示数据为35个工作日、三个示例代码的合成价格，未模拟真实节假日。
用户CSV与演示不可混用；重置工作区会删除模拟记录与行情，保留分析报告和用量。

## 本版已实现

- 密码散列、8小时可撤销会话、注册/登录限流、私有账户与后端资源隔离。
- 自选、日线图、CSV验证、不可覆盖历史快照、来源标识及历史日期截断。
- 持久化研究任务、子进程隔离、超时、取消、重启失败恢复及额度释放。
- 确定性数据核对报告（不是LLM输出）、JSON导出；真实多代理研究适配见下。
- 模拟资金、买入冻结、T+1、卖出冻结、限价开盘撮合、撤单、资金流水及幂等。
- 月度额度、套餐到期、开发测试激活、后端权限检查。
- 自定义支付适配回调验签、金额校验、事件去重；真实创建支付订单返回503。
- 响应式界面、Windows启动脚本、独立Linux单主机Docker部署配置。

- 模拟器限有限沪深主板代码：600/601/603/605、000/001/002。

- 未生成Windows原生安装包、安卓APK或iOS安装包；手机目前使用响应式网页。
- 未运行真实模型/券商/行情/支付集成测试，也未部署到用户主机。

## 可选真实TradingAgents内部研究

安装仓库原项目依赖（仓库根目录 `pip install .`），在服务器环境配置模型密钥。
设置 PRODUCT_INTERNAL_RESEARCH=true 和 PRODUCT_INTERNAL_EMAILS=准确的内部账户邮箱。
重启后该账户在自选行情可选择内部多代理引擎。没有授权的其他用户无法调用或读取。
内部引擎拒绝合成演示数据。原引擎使用自己的数据源，不代表复现导入CSV的完整历史环境。
上游日志被隔离；每个任务有独立临时记忆与缓存目录，结束后删除。
本版不共享跨任务策略记忆，避免串账户和历史信息污染。

模型费用由所配供应商产生；一次任务1个产品额度不是token或人民币报价。
超时/取消后本产品会终止本地子进程，但供应商可能仍已计费。

## Linux部署

```bash
docker compose -f product/deploy/compose.yaml up -d --build
```

此命令用于独立Linux服务器，不适用于已经核查的MyPlace免费PHP空间。
默认API仅映射宿主机127.0.0.1:8765，配置HTTPS反向代理后再对外开放。
容器默认仅安装产品依赖，不启用真实研究引擎。

**仅支持单API进程/单worker，不要开多个Uvicorn worker，也不要水平扩容。**
运行中的任务重启后失败，排队任务继续；失败任务不自动再次调用收费模型。
SQLite用于单机试运行；规格中的PostgreSQL/Redis和分布式worker是后续迁移目标，尚未实现。
数据库在持久卷，不放网站目录；备份需要使用SQLite backup API并验证恢复，不能裸复制WAL数据库。

## MyPlace静态前端

本版前端采用无构建依赖的原生ES模块，以降低免费空间部署复杂度；未采用规格候选React/Tauri。
此选择不等于移动端/桌面端安装包已经完成。

将 product/web/index.html 放文档根目录；其余web文件放根目录的 assets/ 中。
修改 assets/config.js 的 HENGYAN_API_BASE 为独立后台HTTPS地址，绝不能放密钥。
服务器PRODUCT_CORS_ORIGINS配置精确前端origin，例如 https://你的前端域名。
不启用跨域Cookie；接口使用Authorization Bearer；会话令牌存浏览器sessionStorage。
确认主机HTTPS和代理处理方式后参考 myplace.htaccess.example 强制HTTPS。
受免费空间脚本校验限制，部署后仍需真机和跨域验证；此配置尚未实际上传。
